## Interpretation, with caution
- There is no proven guaranteed viral template and design appearance alone is not a substitute for useful information.
- Test a hook/visual surprise in the first 1–3 seconds, not a predictable multi-second logo opening.
- Aim for visible readable Japanese captions and specific, helpful outcomes; switch visual treatment to match the lesson instead of applying one exact five-slide layout to everything.
- Prefer original demonstration screens, typographic animations, meaningful comparisons, checklist reveals, before/after examples, and short graphical transitions rather than unauthorized borrowed reels.
- Avoid overloading mobile-safe areas (especially bottom, right-side icon column, and edges).
- Reassess views, reach, saves, shares, and follower outcomes only after the content has had similar time to circulate. Separate correlation from causation.

## Creative families to rotate
A. Problem → solution: show the everyday struggle, the one clear fix, sample instruction, caution, save CTA.
B. Three-step checklist: point 1, 2, 3 visibly advance; give complete reusable prompt in caption.
C. Before/after: vague prompt vs. precise prompt, explain the difference, include an actionable example.
D. Chat/app demonstration: simulated UI labeled as a *mockup*, showing a user request turning into structured output; never fake real screenshots or actual users.
E. Visual data/diagram: timeline, decision tree, or comparison card in a distinct composition.
F. Rapid Q&A: direct question, answer reveal, one next step.
G. Mistake → correction: common error, corrected wording, effect and verification.

## Canary experiments
- Rotate hook families and layout variants across scheduled slots.
- Introduce true motion (slow camera pan or typography reveal), but keep text legible.
- Test 10–25 second versions when supported by renderer and compare age-matched view/share/save metrics.
- Do not silently change daily frequency or buy engagement.

## Current integration limitation
Canva is connected for interactive design work, but automated Canva-to-GitHub asset export via the available connector is not supported in this integration. Therefore GitHub Actions uses a locally reproducible Python/FFmpeg animation engine, while Canva designs serve as editable reference art and manually obtainable assets. Do not represent them as a fully synchronized pipeline.
